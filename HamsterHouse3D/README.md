# 🐹 Хомячий домик 3D (Android)

3D-игра про хомячков: three.js внутри Android WebView.

## Как собрать APK через GitHub
1. Создай новый репозиторий на GitHub и загрузи туда ВСЁ содержимое этой папки (включая скрытую папку `.github`).
2. Открой вкладку **Actions** → workflow **Build APK** запустится сам (или нажми *Run workflow*).
3. Через 3–5 минут открой завершённый запуск → внизу **Artifacts** → скачай `HamsterHouse3D-apk` (zip с `app-debug.apk`).
4. Установи APK на телефон (разреши установку из неизвестных источников).

## Если меняешь код игры
Исходники — в `web/src`. После правок:
```
cd web && npm install && ./build.sh
```
Скрипт пересоберёт `app/src/main/assets/game.js`. Проверить в браузере: открыть `app/src/main/assets/index.html` через локальный сервер (`python3 -m http.server -d app/src/main/assets`).

## Что внутри
- `web/src/hamster.js` — модель хомячка (сделана из кода), поведение, потребности
- `web/src/world.js` — клетка, домик, колесо, мисочка, поилка, тоннель, день/ночь
- `web/src/main.js` — управление, интерфейс, размножение, сохранение
- `web/src/audio.js` — звуки (синтез, без файлов)
