# Облачко: Большой забег — сборка APK (версия 1.1)

3D-раннер на Three.js + Capacitor 7. Модели сделаны в Blender (`blender_src/`), музыка синтезирована (`audio_src/`).
Игра работает офлайн, прогресс хранится на устройстве.

## Что нового в 1.1.1
* **Адаптация под телефон:** в горизонтальном режиме карточка главы и пауза/итоги раскладываются в две колонки,
  кнопки всегда на экране; если текст не помещается — окно прокручивается. Учтены вырезы экрана (safe area).
* Глава 1: вместо листков накладной теперь собираем **5 писем**.

## Что нового в 1.1
* **Новые герои на двух лапах.** Облачко, Пуговка и Белла бегают на задних копытцах, передние работают как руки.
  Облачко — белая шерсть, тёмная мордочка, бирюзовый шарф и клевер в чёлке.
* **Анимация бипеда:** бег с отмашкой рук, прыжок с поднятыми руками, падение с «крыльями»,
  подкат — барашек сворачивается в шерстяной клубок и катится, радость на финише.
* **Первый запуск:** один раз спрашиваем «Телефон или планшет», затем один раз — «Поверните устройство»
  (анимированная иконка). Выбор сохраняется; на следующих запусках ориентация блокируется сама.
  Сменить: Настройки → Экран (Горизонт. / Вертик. / Авто).
* **Новая иконка и заставка** (`assets/`), уже сгенерированы для Android в `android/app/src/main/res/`.
* **Новый генератор трассы:**
  - в каждом ряду гарантирован проход, достижимый из прошлой полосы;
  - «ворота» всегда открыты не дальше одной полосы от текущего пути;
  - монеты никогда не лежат внутри препятствий: дуга повторяет реальную траекторию прыжка
    (с учётом скорости), под арками — низкая линия для подката, на крыше вагона — линия по крыше;
  - дорожка монет ведёт по безопасному пути и плавно меняет полосу в просвете между рядами;
  - бонусные монеты над более рискованной полосой;
  - бонусы и предметы ставятся на безопасный путь; встречный транспорт «съедает» монеты и сдвигает бонусы;
  - новые паттерны: ворота, зигзаг, барьеры подряд, тоннель из арок; расстояния растут вместе со скоростью.
* **Android:** полноэкранный режим без системных панелей, экран не гаснет, вибрация, подпись релиза через переменные окружения.

## Вариант 1 — APK в облаке GitHub (без Android Studio)
1. Создайте репозиторий на GitHub и загрузите туда содержимое этой папки (без `node_modules`).
2. Откройте вкладку **Actions** → workflow **Build APK** → **Run workflow** (он также запускается на каждый push).
3. Через 5–8 минут в запуске появится артефакт **oblachko-apk** → внутри `app-debug.apk`.
   Его можно сразу ставить на телефон (разрешите установку из неизвестных источников).

Подписанный релиз для Google Play: в **Settings → Secrets → Actions** добавьте
`KEYSTORE_BASE64` (keystore в base64), `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` —
тогда workflow соберёт ещё `app-release.apk` и `app-release.aab`.

Создать keystore: `keytool -genkey -v -keystore release.jks -alias oblachko -keyalg RSA -keysize 2048 -validity 10000`,
в base64: `base64 -w0 release.jks`.

## Вариант 2 — на своём компьютере
Нужны **Node.js 20+**, **Android Studio** (Android SDK) и **JDK 21** (Capacitor 7 требует 21).
Папка `android/` уже создана и настроена.

```bash
npm install
npm run android:apk        # собирает игру, синхронизирует, ./gradlew assembleDebug
# файл: android/app/build/outputs/apk/debug/app-debug.apk
```
Или `npm run android:open` → Android Studio → **Build → Build APK(s)**.
Релиз: `npm run android:release` с переменными `OBLACHKO_KEYSTORE`, `OBLACHKO_KEYSTORE_PASSWORD`,
`OBLACHKO_KEY_ALIAS`, `OBLACHKO_KEY_PASSWORD`.

## Вариант 3 — конструкторы «сайт → APK»
Возьмите `dist/oblachko_single.html` (всё встроено в один файл). Блокировка ориентации там работает
только если конструктор сам её поддерживает — выставьте в нём «альбомная ориентация».
Если конструктор не сохраняет localStorage, вопрос «Телефон/Планшет» будет появляться при каждом запуске —
в Capacitor-сборке (варианты 1–2) такого нет.

## Изменить игру
* Главы, тексты, цены — `src/data.js`; генератор трассы — `src/main.js` (раздел «row generator»).
  После правок: `npm run build` и `npm run build:single`.
* Герои: `python3 blender_src/heroes.py` (нужен `pip install bpy`).
* Иконка: `python3 blender_src/icon_render.py 1024 assets/icon_hero_render.png 1.1 0.68`,
  затем `python3 tools/make_icons.py` и `npm run android:icons`.
* Проверка в браузере: `npm run serve` → http://localhost:8080. Управление на ПК: стрелки / WASD / пробел, P — пауза.
