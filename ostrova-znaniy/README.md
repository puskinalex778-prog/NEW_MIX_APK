# Острова знаний — детская обучающая игра

Игра для 1–4 классов: математика, русский язык, сказки, окружающий мир и английский.
Острова, сюжет «Небесные мосты», Мастерская умножения и Работа над ошибками.

## Как собрать APK через GitHub

1. Загрузите **всё содержимое этой папки** в репозиторий на GitHub, включая скрытую папку `.github`.
2. Откройте вкладку **Actions**. Сборка «Сборка APK» запускается сама после каждого push.
   Запустить вручную: **Actions → Сборка APK → Run workflow**.
3. Когда сборка закончится (5–8 минут), откройте её и внизу, в разделе **Artifacts**, скачайте
   `ostrova-znaniy-apk`. Внутри будет `app-debug.apk`, его можно установить на телефон.

## Где что лежит

| Файл | Что внутри |
|---|---|
| `src/content.js` | **Все задания и текст сюжета.** Чтобы добавить задание, редактируйте этот файл |
| `src/game.js` | Движок: экраны, перетаскивание пальцем, проверка ответов, звёзды |
| `src/art.js` | Графика: острова, персонажи, анимированный фон, конфетти, звуки |
| `src/style.css` | Оформление |
| `build.py` | Собирает всё в один файл `www/index.html` (GitHub запускает его сам) |
| `www/index.html` | Готовая игра, открывается в любом браузере даже без интернета |

## Типы заданий (src/content.js)

```js
T.choice('Заголовок', 'Вопрос', 'правильный', ['неверный1', 'неверный2'], 'Подсказка')
T.sort('Заголовок', [['a','Группа 1','🍎'], ['b','Группа 2','🐾']], [['слово','a'], ['кот','b']], 'Подсказка')
T.order('Заголовок', ['первый', 'второй', 'третий'], 'Подсказка')     // правильный порядок
T.match('Заголовок', [['🐈','cat'], ['🐕','dog']], 'Подсказка')         // слева: текст, эмодзи или цвет '#ff0000'
```

`sort`, `order` и `match` решаются перетаскиванием карточек пальцем
(или нажатием на карточку, а потом на место для неё).

## Название и иконка

Название приложения и его ID задаются в `capacitor.config.json` (`appName`, `appId`).
